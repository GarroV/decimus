# Инструкции для агентов (Codex и другие)

Правила работы в этом репозитории — в `CLAUDE.md`, они действуют для любого агента, не только для Claude. Прочитать его целиком до первой правки.

Отдельно, потому что это уже случалось: **учётку на проде заводить только после явного «да» владельца** (сказать, какую, зачем и на сколько). Проверки — на стенде, не на проде. После проверки — обязательная чистка через подтверждение: предложить владельцу снять учётку, по «да» заморозить (`tools/web_user.py freeze`) и показать, что среди действующих её нет. Подробно — `CLAUDE.md`, раздел «Тестовые учётки на проде» (D742).
