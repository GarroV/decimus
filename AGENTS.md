# Инструкции для агентов (Codex и другие)

Правила работы в этом репозитории — в `CLAUDE.md`, они действуют для любого агента, не только для Claude. Прочитать его целиком до первой правки.

Отдельно, потому что это уже случалось: **тестовые учётки на проде не заводить** без явного «да» владельца. Проверки — на стенде, не на проде. Разрешил — учётка записана (логин, зачем, до когда) и после проверки замораживается или удаляется (`tools/web_user.py freeze`). Появление нового главного админа на проде владелец видит в канале оповещений (D742).
