## Что это

Карта отвечает на вопрос «кто и через какую дверь входит в Децимус, что ему видно,
что он может менять и что сервис сам отдаёт наружу». Подробные контракты — по
ссылкам; здесь только сводка.

## Двери

| Дверь | Кто входит | Как опознаётся | Что открыто | Подробно |
|---|---|---|---|---|
| Веб-админка | люди с учёткой, 6 ролей | пароль или Google (учётка с привязанной почтой Google — только Google; учётка УК — только аккаунт домена компании, `GOOGLE_HQ_DOMAINS`, D430); сессия 12 ч; запрет при переборе | по роли и пространству: УК — вся сеть, партнёр — свои страны; запись — только своё пространство; запись только со своей страницы (`app._install_origin_gate`) | `docs/12-web-admin.md` |
| Telegram-бот | привязавшие Telegram к учётке | одноразовая ссылка из админки (10 мин) | своя проверка в своём пространстве; команды круга MCP — участникам круга | `docs/06-mvp-bot.md` |
| Мини-апп обхода | те же | подпись Telegram, не старше 6 ч | своя проверка и свои кадры | `docs/13-walk-mini-app.md` |
| API для сервисов (`/api/v1/*`) | сервисы по ключу (Swarm) | ключ в заголовке, в базе отпечаток | только чтение; право на каждый метод; страны и срок у ключа | `docs/12-web-admin.md`, «API чтения для Swarm» |
| MCP | Claude у людей из круга доступа | личный ключ (отпечаток в базе) | инструменты по допускам пространства | `docs/furca/blocks/mcp.md` |
| Без входа | любой | — | вход, статика, вход через Google; остальное ведёт на вход | `src/web/auth.py: OPEN_ENDPOINTS` |

## Роли веб-админки

`superadmin`, `admin`, `control`, `auditor` в пространстве УК; `admin`, `auditor`
у партнёра. Охват чтения — `src/db/reach.py`, кто кем управляет —
`src/web/access_policy.py`, заслоны разделов — `src/web/app.py`
(`_install_hq_gate`, `_install_control_gate`, `_install_methodology_gate`).
Рейтинги, карты и агрегаторы видят все роли (D327); загрузки и настройки
рейтингов — главный админ, админ УК и контроль (`may_manage_ratings`).
Контроль в вебе видит только «Рейтинги» и «Пользователи» (свои дела и люди
контролинга) и после входа попадает в «Рейтинги»; «Главной», «Проверок», карточек
проверок и пиццерий у него нет даже на чтение (D420; `sections.CONTROL_SECTIONS`).

## Права ключа API

Восемь прав, по одному на адрес (D425): `ratings:scores`, `ratings:checkups`,
`ratings:violations`, `maps:ratings`, `aggregators:ratings`, `inspections:list`,
`inspections:detail`, `inspections:violations`. Перечень с адресами —
`docs/12-web-admin.md`. Персональных данных в ответах нет, кроме имени
девелопера страны в баллах и формулировки записи в подробностях проверки.

## Что уходит наружу

| Куда | Что |
|---|---|
| OpenAI | вопрос и комментарий аудитора, кадры кухни, голос, тексты записей и отчёта; распознавание просит не хранить ответы (`store=False`) |
| Telegram | всё, что идёт через чат: кадры, голос, PDF |
| Google | при входе — почта и профиль; черновик письма партнёру в Gmail вошедшего — только если доступ выдал его же аккаунт (D176) |
| Cloudflare | весь трафик админки и MCP (Worker на входе) |
| Swarm | то, что открывают права его ключа |
| Pointer, агрегаторы, публичный API Dodo | только наши запросы на чтение |
