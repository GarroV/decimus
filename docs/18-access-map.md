## Что это

Карта отвечает на вопрос «кто и через какую дверь входит в Децимус, что ему видно,
что он может менять и что сервис сам отдаёт наружу». Подробные контракты — по
ссылкам; здесь только сводка.

## Двери

| Дверь | Кто входит | Как опознаётся | Что открыто | Подробно |
|---|---|---|---|---|
| Веб-админка | люди с учёткой, 6 ролей | пароль или Google; сессия 12 ч; запрет при переборе | по роли и пространству: УК — вся сеть, партнёр — свои страны; запись — только своё пространство; запись только со своей страницы (`app._install_origin_gate`) | `docs/12-web-admin.md` |
| Telegram-бот | привязавшие Telegram к учётке с ролью аудитора или админа (контролю закрыт, D420); сотрудники УК по списку окружения без привязки (D290) | одноразовая ссылка из админки (10 мин); роль и отключение учётки сверяются на каждом апдейте (кэш 60 с) | своя проверка в своём пространстве; команды круга MCP — участникам круга, в охвате своего пространства | `docs/06-mvp-bot.md` |
| Мини-апп обхода | те же | подпись Telegram, не старше 6 ч; выпуск токена Claude и правка круга — не старше 5 мин | своя проверка и свои кадры | `docs/13-walk-mini-app.md` |
| API для сервисов (`/api/v1/*`) | сервисы по ключу (Swarm) | ключ в заголовке, в базе отпечаток | только чтение; право на каждый метод; страны и срок у ключа | `docs/12-web-admin.md`, «API чтения для Swarm» |
| MCP, вход через сайт | Claude у любого с учёткой | OAuth (D417), учётка, роль и отключение читаются на каждом вызове | инструменты по роли учётки (`src/mcp/policy.py`) | `docs/furca/blocks/mcp.md` |
| MCP, личный токен | Claude у людей из круга доступа | ключ из бота или мини-аппа, выпущен на учётку сайта; срок 30 дней (`MCP_TOKEN_TTL_DAYS`); отключение учётки, смена роли или пространства, отвязка бота гасят его сразу | инструменты по роли учётки (`src/mcp/policy.py`), снятия проверок нет | `docs/furca/blocks/mcp.md` |
| MCP, служебный токен | владелец стенда | ключ из `MCP_TOKENS` в `.env`, без срока и без роли | все инструменты пространства по его допускам; снятие — только по `MCP_RETRACTION_TOKENS` | `docs/furca/blocks/mcp.md` |
| Без входа | любой | — | вход, статика, вход через Google; остальное ведёт на вход | `src/web/auth.py: OPEN_ENDPOINTS` |

## Роли веб-админки

`superadmin`, `admin`, `control`, `auditor` в пространстве УК; `admin`, `auditor`
у партнёра. Охват чтения — `src/db/reach.py`, кто кем управляет —
`src/web/access_policy.py`, заслоны разделов — `src/web/app.py`
(`_install_hq_gate`, `_install_control_gate`, `_install_methodology_gate`).
Рейтинги, карты и агрегаторы видят все роли (D327); загрузки и настройки
рейтингов — главный админ, админ УК и контроль (`may_manage_ratings`).

Одна учётка на все двери: бот, мини-апп и личный токен MCP опознают человека
через привязку бота к учётке сайта и читают её роль, пространство и отключение
так же, как веб (аудит 12.10). Поле — бот и мини-апп — открыто аудитору и
админам (`src/domain/tenants.py: FIELD_ROLES`); права в Claude — матрица
`src/mcp/policy.py` (контроль — только рейтинги, D420). Круг доступа к Claude
поделён по пространствам (`src/db/mcp_access.py: in_scope`): участник из
пространства партнёра видит и правит только людей своего пространства.

## Права ключа API

Восемь прав, по одному на адрес (D425): `ratings:scores`, `ratings:checkups`,
`ratings:violations`, `maps:ratings`, `aggregators:ratings`, `inspections:list`,
`inspections:detail`, `inspections:violations`. Перечень с адресами —
`docs/12-web-admin.md`. Персональных данных в ответах нет, кроме имени
девелопера страны в баллах и формулировки записи в подробностях проверки.

## Что уходит наружу

| Куда | Что |
|---|---|
| OpenAI | вопрос и комментарий аудитора, кадры кухни, голос, тексты записей и отчёта; распознавание просит не хранить ответы (`store=False`) |
| Telegram | всё, что идёт через чат: кадры, голос, PDF |
| Google | при входе — почта и профиль; черновик письма партнёру в Gmail автора |
| Cloudflare | весь трафик админки и MCP (Worker на входе) |
| Swarm | то, что открывают права его ключа |
| Pointer, агрегаторы, публичный API Dodo | только наши запросы на чтение |
