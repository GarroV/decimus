## Где что может сломаться

- Домашний сервер спит: «Migros ответил HTTP 403 (через домашний сервер)» или «домашний сервер не отвечает» — строка «СБОЙ» в журнале сбора, △ у устаревших оценок, одна тревога в канал FURCA.
- Если первые три точки подряд не ответили (`collect.GIVE_UP_AFTER`), остальные не опрашиваются.
- Новую пиццерию Migros сбор сам не найдёт: фильтра по бренду у поиска нет, только привязка по ссылке или строка справочника.
