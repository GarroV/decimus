## Где что может сломаться

- Ретранслятор без обновления на запрос с `host` отвечает 404: Армения даёт сбой в журнале сбора (Беларусь не затронута). Обновлять сначала ретранслятор, потом прод.
- Домашний сервер засыпает и сам не просыпается: «Яндекс Еда ответила HTTP 429 (через домашний сервер)» или «домашний сервер не отвечает».
