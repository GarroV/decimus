# Блок: web

## Назначение

Веб-админка управляющей компании: то, что сегодня доступно только через бота и
MCP, получает экран. Объём спринта — **базовая часть веб-версии** (D133), а не
вся она: каркас с честными заглушками (D138) и раздел «Проверки».

Раскладка берётся из прототипа владельца (`Бриф системы аудитов Decimus 2/
Dodo Audit Prototype v2.dc.html`, 9 разделов навигации), стиль — из
дизайн-системы линейки `GarroV/forma` (`dodo/core/dodo-ds.css` +
`dodo/decimus/domain.css`). Палитра `#5B57F2` и пара Space Grotesk / Manrope из
прототипа в продукт **не переносятся** (D136). Копия `dodo-ds.css` в папке
эталона разошлась с каноном — сверять с `forma`.

## API-контракт

Блок **ничего не считает сам**. Оценка, буква, разбивка по зонам, сроки —
только через уже существующие двери:

| Что нужно экрану | Чем берётся | Запрет |
|---|---|---|
| История проверок, карточка проверки | `src/db/queries.py` | свой SQL поверх тех же таблиц |
| Снятие проверки | `src/db/retract.py` (D086/D089) | второе понятие «удаление» |
| Состав методики, зоны, классы | `src/domain` | чтение `data/*.csv` напрямую |
| Правка методики (позже, T320) | те же двери, что MCP/CLI (D049, D050) | вторая копия правил версионирования |

Веб — **читатель**, а не второй владелец правды. Схему данных этот блок в
первой волне не меняет.

### Признак «построен / не построен»

Единственный источник — **данные** (реестр разделов в коде блока), а не
разметка на каждом экране: иначе он разойдётся с фактом молча (D138). Раздел с
признаком «не построен» получает ленту в навигации и явный экран «ещё в
разработке» при входе, а не пустую или декоративную страницу.

В объём **не входят и показываются непостроенными** (D139): «Календарь»,
«Назначить проверку», планирование как сущность.

## Зависимости

`db` (история проверок, снятие), `domain` (методика, зоны), `mcp` (границы
арендатора и прав — переиспользовать, не дублировать).

## Рамка стека

Задаётся диспетчером, конкретный фреймворк выбирает блок с обоснованием и
записывает в отчёт (D147):

- Python, тот же образ и `docker-compose.yml`, что у бота и MCP;
- **серверный рендеринг**, без сборщика и без Node в образе: дизайн приходит
  готовым CSS из `forma`, а не React-компонентами;
- синхронный код — как весь остальной продукт (`psycopg`, `openai`);
- статика дизайн-системы кладётся копией с указанием версии-источника, чтобы
  расхождение с `forma` было видно.

## Definition of Done блока

- [ ] Раздел «Проверки» открывается в браузере и показывает проведённые
      проверки: список, карточка, снятие — на данных, а не на заглушках.
- [ ] Все 9 разделов прототипа есть в навигации; непостроенные помечены лентой
      и дают экран «ещё в разработке» (D138).
- [ ] Ни один процент и ни одна буква не посчитаны в этом блоке заново.
- [ ] Язык интерфейса — параметр, а не константа (требование `CLAUDE.md`);
      тексты заведены на обоих языках (`product-i18n`).
- [ ] Проверено живым запуском в браузере, а не только тестами.
- [ ] Гейты проекта зелёные: `make check` (формат, линт, типы, тесты, мёртвый
      код, границы модулей). Новый пакет `src/web` внесён в контракты
      `import-linter` слоем над `db`/`domain`, обратный импорт запрещён.
- [ ] `docs/` пополнены: новая поверхность описана там же, где остальные.
