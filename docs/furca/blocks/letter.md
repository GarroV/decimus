# Блок letter — форматирование письма партнёру (T353, остаток #332)

**Что может пользователь после блока.** Аудитор на экране письма выделяет слова
жирным, курсивом, зачёркивает и ставит ссылку; сохранённое письмо и черновик
Google несут тот же вид, а получатель без HTML видит честный текст.

## Контракт

**Форма хранения** (`partner_letters.body`, схема не менялась): текст, где перевод
строки — значимый `\n`, плюс строчная разметка ровно из четырёх элементов:
`<b>`, `<i>`, `<s>`, `<a href>`. Символы `& < >` в тексте экранированы. Старые
письма простым текстом читаются этой же формой без миграции: стоящий отдельно
`<` и кириллица после `<` разбором остаются текстом.

**Санитайзер** — `src/web/letter_markup.py`, белый список с пересборкой вывода
(вход разбирается `html.parser`, выход строится заново, входная строка наружу не
попадает):

| Функция | Вход → выход |
|---|---|
| `sanitize(raw)` | любая строка → каноническая форма выше |
| `from_plain(text)` | заготовка движка (простой текст) → каноническая форма |
| `to_plain(markup)` | → текст без разметки; ссылка — «текст (адрес)» |
| `to_email_html(markup)` | → HTML-часть письма, перевод строки = `<br>` |

Правила белого списка: синонимы браузера сводятся к четырём (`strong`→`b`,
`em`→`i`, `strike`/`del`→`s`); блочные (`div`, `p`, `br`, `li`, …) становятся
переводами строки; прочие теги выбрасываются с сохранением текста;
`script`/`style`/`iframe`/… выбрасываются вместе с содержимым; у ссылки остаётся
только `href` со схемой `http`/`https`/`mailto` (управляющие символы — отказ),
иначе ссылка снимается и остаётся её текст; вывод всегда сбалансирован.

**Где санитизация стоит.** При сохранении — `inspections.remember_letter` (через
неё идут и «Сохранить», и «В черновики Google»). При выводе — фильтр шаблона
экрана письма, сборка MIME черновика (`google_mail.letter_message`).

**Выгрузки файлом нет** (D169): маршрут, кнопка, тексты и тесты сняты.

**Редактор** — `static/letter.js`, без библиотек: `contenteditable` +
`execCommand`, панель из четырёх кнопок, вставка — только простым текстом,
перед отправкой формы разметка редактора уходит в поле `text`. Без JS работает
прежнее поле с разметкой как текстом. CSP не менялась, встроенных скриптов нет.
