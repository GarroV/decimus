# Блок access2 — доступ, волна 2 после пространств

Ветка `feat/wave2-access`. Что пользователь получает: человек меняет свой пароль
сам с экрана «Профиль»; админ пространства задаёт человеку почту для входа через
Google и роль на вкладке «Пользователи»; опечатка в коде пространства — громкий
отказ, а не новое пространство.

## Контракт

- `src/domain/checklist_store.py` — чтение раскладки хранилища методик и правило
  годности к боту (`bot_block`). `src/mcp/checklist_layout.py` переиздаёт имена и
  переводит `ChecklistStoreError` в `ChecklistError`; `src/mcp/checklists.py:
  bot_block` уточняет «пусто»/«не опубликовано» по журналу.

- Свой пароль: `POST /users/password` (`src/web/profile.py`) → `web_access.change_own_password`
  → функция базы `change_own_password(token, old_hash, new_hash)` (`0032`, `security definer`,
  execute только `dodo_audit_app`). Счётчик — `admit_attempt` тем же тенантом стенда
  (`auth.throttle_tenant()`) и ключами, что у входа.

- Роль и почта: `POST /users/role`, `POST /users/email` (`src/web/people.py`) → `set_role`,
  `set_email` под ролью администратора истории; заслон `_hq_admin_only` (админ УК, любое
  пространство). `AccountRow.email` в перечне.

- #481: `src/db/space_guard.py: require_space(cur, code, error=...)` — тем же курсором, что пишет;
  тесты, заводившие пространства побочным эффектом, заводят их явно
  (`db_harness.завести_пространства`, исполнитель optio).

## Открыто

- D288: админ партнёра людьми не управляет — оставлено как было, правку ему не открывал.
- «Доверенные почты» не делались (открытый вопрос владельца, #399).
- Свою роль сменить нельзя (отказ `role.self`) — по образцу «себя отключить нельзя».

- Развилка #324 о правах: бриф требует «роль может обновить только `password_hash` своей
  строки» — это вариант 3 из issue (функция базы), в виде «строку выбирает живая сессия»:
  scrypt в Postgres не сверить, текущий пароль сверяет приложение. Владельцу — на сверку.
- Экран: карточка «Сменить пароль» на вкладке «Пользователи», не отдельный раздел
  «Профиль» (навигация и так шире шести пунктов). Владельцу — на сверку.
- Вёрстка перечня людей (сверка norma): кнопки роли и почты подписаны по-разному
  («Назначить» / «Сохранить»), при тесноте переносятся под поле; перечень помещается в
  карточку на 1280 и 1440 (замер ширины таблицы ≤ ширины обёртки). На телефоне перечень
  скрыт ядром дизайн-системы (`dodo-ds.css` `.table-wrap { display: none }`) — было до блока.
