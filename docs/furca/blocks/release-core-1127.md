# Общий пакет выпуска

Complexity: hard

Владелец: диспетчер пакета. Исправления по находкам, даты поездок, RU/EN PDF
и письма, технический контроль и редактор важных точек. Сведение интерфейсного
и партнёрского блоков, миграций и реальных пользовательских сценариев.

Миграции: 0136 исправления; 0137 языковые документы; 0138 технический снимок;
0139 технические подтверждения; 0140–0143 зарезервированы партнёрскому блоку.
0144 для кластеров только после решения владельца. Исходные проверки и их оценка
не переписываются. Наборы технических точек версионируются с методикой.

Рабочие копии исходных сессий не изменяются. К выпуску идут нейтральные коммиты
общего пакета. Перед публикацией проверяются новые материалы и новая история
коммитов на перенос разговоров и секретов.

Приёмка: только изменённые сценарии и ближайшие отказы, затем общая проверка
на MUSPELHEIM и внешний смоук после выкладки. Полный набор и аудит не запускаются.
Разрешение на выпуск дано владельцем в текущем разговоре; действует ночное окно.
