# Приёмка объединённого выпуска на стенде

Дата: 27.11.2026. Исходная сборка: `09e2b77e` с итоговыми изменениями общего
пакета на стенде MUSPELHEIM. База и хранилище файлов изолированы от production.
Проверки выполнены через настоящий HTTP и Chrome for Testing, без подмены
ответов приложения. Полный набор тестов не запускался.

## Пройденные сценарии

- Исправления: файл и комментарий по конкретной находке, оригинал скачан с тем
  же SHA-256; JPEG-превью доступно. Отправка на проверку, возврат с обязательной
  причиной, повторная отправка, отказ устаревшему решению, подтверждение и
  повторное открытие работают. История и материалы сохраняются. После закрытия
  общий комментарий доступен, новые доказательства закрытого пункта отклоняются.
  Партнёр не подтверждает исправления проверки УК; гостю запись запрещена.
- Карточка: отправка комментария настоящей браузерной формой; при ширине 390 px
  нет горизонтального переполнения; фильтры реестра изначально свёрнуты.
- Партнёр: тур открывается, следующий шаг работает, закрытие запоминается.
  Обратная связь с фото сохраняется и видна администратору УК; фото недоступно
  партнёру по прямой ссылке. Отметка разбора сохраняется; пустой текст и файл
  с неподдерживаемым содержимым отклоняются. Telegram на стенде не настроен.
- Пространства: администратор УК меняет и восстанавливает лимиты; нулевой лимит
  числа проверок и правка лимитов партнёром отклоняются. Заморозка пространства
  закрывает действующую партнёрскую сессию; разморозка возвращает возможность
  входа. Заморозка УК и заморозка пространства самим партнёром запрещены.
- Технический контроль: явный ответ сохраняется, сокращает число обязательных
  пропусков и читается после перезагрузки; устаревшая ревизия получает 409.
  Кнопка завершения при обязательных пропусках возвращает к контрольным точкам.
  Матрица истории видима; мобильный экран не имеет горизонтального переполнения.
- Редактор: браузерное сохранение создаёт новое издание с прежним ID точки.
  Устаревшая форма не изменяет новое издание и показывает сообщение о конфликте
  (HTTP 200, как другие формы редактора). Отдельная публикация проверена по
  отметке действующей версии. Идущая проверка остаётся на закреплённом издании.
- Документы: исходный EN PDF обычной проверки и исходный RU PDF технической
  проверки скачаны по HTTP с кодом 200. Недоступный перевод при отсутствии
  ключа модели на стенде даёт 503; свежий вызов перевода здесь не проверялся.
  Производные переводы и повторное использование кэша проверены отдельно в
  блоке сохранения оригиналов; повторный платный вызов на этой приёмке не нужен.

## Исправлено по результатам приёмки

В форме обратной связи после успешного сохранения кнопка отправки действительно
скрывается. Повторное открытие восстанавливает доступность полей и кнопки.
Подсказка и результат на RU/EN явно называют место хранения и получателя:
администраторы УК, «Администрирование → Обратная связь». Ссылка на закрытый для
партнёра раздел не создаётся. Две новые операции технического контроля включены
в явный перечень разрешённых действий демо.

После исправлений: 57 проверок формы обратной связи и контракта демо прошли;
14 проверок текстового каталога прошли; Ruff, формат и `git diff --check` чисты.
Повторная проверка браузером подтвердила новый текст, скрытие кнопки и повторное
открытие формы.
