Почта остаётся публичным идентификатором входа, новые внутренние ключи создаются
через UUID. Имена, существующие учётки и отложенное удаление main сохранены.
Заморозка, лимиты и готовность встроены в текущую страницу партнёрских людей;
старый экран не подменяет её.

Месячный порог модели останавливает новые запросы по уже учтённому расходу
с коротким кэшем исходной реализации. Начатые запросы не отменяются, поэтому
итоговый расход может превысить порог. Подпись на экране разъясняет это поведение. Конкурентный лимит количества проверок удерживается
транзакционной блокировкой пары пространство/точка.
