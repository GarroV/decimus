# Веб-админка на MUSPELHEIM (до 26.09.2026)

> **Исторический документ, не инструкция.** Описывает, как админка стояла на площадке MUSPELHEIM до переезда на VPS 26.09.2026.
> Сохранён, чтобы было понятно, откуда взялись `WEB_URL_PREFIX` и монтирования методики. Нынешний прод — [`../08-deploy.md`](../08-deploy.md).

## Было до 26.09.2026 — MUSPELHEIM

Площадка MUSPELHEIM, отдельный compose-проект `decimus-web`
(`C:\projects\decimus-web`). Отдельный он по ОБРАЗУ и запуску, а не по данным:
админка показывает **боевые** проверки (решение D161) и для этого ходит в базу
`decimus-infra` по её сети, в тенант `default`. Боевые контейнеры при этом не
трогаются вовсе — ни образы, ни бот, ни MCP.

Читает она не только базу. Письмо партнёру пересобирается по методике ТОЙ
версии, которой помечена проверка, поэтому стенду в надстройке
(`docker-compose.override.yml`, в репозиторий не уезжает) отданы **боевые**
методика и полка снимков, оба `:ro`:

| Что | Откуда на стенде | Зачем |
|---|---|---|
| методика | `C:/projects/decimus/data` → `/app/data:ro` | версия, по которой считается сегодня |
| полка снимков | том `decimus-infra_state` → `/app/state:ro` (пишет в него бот и сервис мини-аппа обхода `walk`, не админка) | версии, по которым считались прошлые проверки |
| хранилище версий методики | том `stand-methodology` → `/app/methodology` | правки состава из раздела «Методика» (D165) |

Своя копия каталога здесь не годится и проверена на себе: при первом смоуке
стенд монтировал собственный пустой `data/`, и экран письма отвечал «проверка
посчитана по версии `local-b9e1adbc238e`, а её снимка нет» на каждой проверке.
Оба монтирования только на чтение: полку пишет бот, методику правят через MCP —
запись отсюда затёрла бы чужое.

Снаружи: **`https://<TAILNET_HOST>/audit`**. Путь, а не порт, и не
свой домен: корень общего входа площадки отдан соседнему продукту, а из трёх
портов Tailscale Funnel свободных нет (443 занят, 8443 закреплён за соседом,
10000 держит наш же MCP). Поэтому админку выделили путём — см. ниже, как это
устроено. Свой домен, когда он появится, снимет и путь, и оговорку.

Внутрь площадки цепочка такая: Funnel → петля хоста `8268` → звено `web-link`
(в сетевом пространстве контейнера) → сервер на петле контейнера `8267`. Порт
наружу по-прежнему не публикуется.
