## Исправление

При выборе предварительной карточки поиск ещё мог удерживать общую сессию
модели. Параллельная проверка класса получала busy/429, а форма показывала
общую просьбу определить класс; отдельный блок с причиной находился ниже
формулировки и комментария. Это воспроизведённый путь ошибки, а не утверждение
о содержимом ответа модели на каждую конкретную фотографию.

Теперь выбранный пункт ждёт завершения поиска, затем проверяется по полному
закреплённому критерию. Поздний результат поиска не перебивает выбор. Изменение
фактов, закрытие формы и ручной класс отменяют отложенную проверку. Нет цикла
автоматических повторов или подстановки предварительного класса вместо итогового.

Блок класса находится до формулировки и комментария. У сохранения видны ожидание,
конкретный вопрос или ошибка; доступен переход к нужному полю либо явный повтор.
Готовый класс позволяет сохранить запись без ручного перевыбора D1/D2/D3.
Открытая до установки страница использует загруженный ранее JS до обновления.
