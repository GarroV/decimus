> D425 (техническая админка доступов), D426 (что берёт Swarm), D427 (агрегаторы со
> всех, защиту не обходим), D428 (без FURCA, карта доступов). Это доделка, а не
> стройка: один исполнитель, по пунктам, каждый пункт — свой PR и выкатка (D363).

## Что строим и зачем

Swarm уже забирает из Децимуса рейтинги и проверки по сервисному ключу (D387, D388).
Дальше сервисов будет больше, а ключ сейчас выпускается командой на сервере. Нужно:
чтобы владелец сам выдавал и отзывал доступы на экране, чтобы каждому сервису
открывалось ровно то, что включено, и чтобы было видно, кто куда ходит. Параллельно —
оценки агрегаторов без ручного сопровождения новых пиццерий.

## Границы

- Защиту площадок («вы не робот», вход) не обходим. Где не достучаться — не берём (D427).
- Сервисам наружу — без персональных данных: ни аудиторов, ни почт, ни Telegram, ни кадров.
- Людям никаких сообщений (правило 7): всё — на экранах.
- MCP — дверь для ИИ-ассистентов людей; её права наследуют роль человека (D411). API — дверь для сервисов; права выдаёт главный админ на «Подключениях» (D425).
