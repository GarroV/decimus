# План: оценки агрегаторов доставки на странице рейтингов (#638, D389)

> Разведка 09–11.10.2026: все страны IMF, 208 работающих пиццерий, 263 пары
> «пиццерия × агрегатор» с оценкой. Рецепты запросов и данные — вне git
> (`workbench/private/decimus/aggregators-2026-10-11/RECIPES.md`, `out/combined.json`).

## Что строим

Бот раз в сутки (D389) собирает оценки пиццерий Додо во всех агрегаторах, где они есть,
кладёт снимок дня в базу и показывает блоком «Оценки в агрегаторах» на странице рейтингов.
Сбой агрегатора виден на странице, а не тишиной. Сделано по образцу оценок карт
(`maps_loader`, `maps_store`, блок `maps`, docs/09).

## Решения

- **Агрегатор — поле данных** (владелец 09.10): одна таблица точек и одна таблица оценок
  на все агрегаторы, новый агрегатор — новый модуль-сборщик, без миграции.
- **Шкала родная**: Wolt — из 10, Glovo — % положительных, остальные — из 5. Пересчёт в
  общую шкалу исказил бы то, что видит гость; страна на агрегаторе — средняя,
  взвешенная числом оценок, в шкале этого агрегатора.
- **Два вида сборщиков.** *Поиск у координат* (Wolt, Bolt Food, Яндекс Еда, Yemeksepeti,
  Trendyol Go, Pyszne.pl): каждые сутки заново от координат каждой работающей
  пиццерии — так сами ловятся новые пиццерии и переезды страниц. *По известной точке*
  (Glovo, Chowdeck): поиск с сервера не работает или его нет; точка берётся из
  справочника привязок, оценка — с сервера по id. Справочник наполняется разово из
  разведки (`python -m src.ratings.aggregators seed <файл>`), новые точки Glovo — тем же
  путём после ручного поиска в браузере.
- **Привязка к пиццерии** — по координатам: ближайшая точка агрегатора не дальше 400 м,
  одна точка — одной пиццерии. Код пиццерии — `UUId` из publicapi, как у карт.
- **Пустой ответ — не «Додо пропал».** Если агрегатор вернул 0 точек, а в прошлый
  удачный сбор было больше, это сбой: журнал `failed`, старые оценки остаются.
- **Браузера в эксплуатации нет** (владелец 11.10: «меня волнует связка с браузером»).
- **Без сообщений людям** (правило 7): только запись в базу и показ на странице.
- Migros Yemek и Talabat — следующим заходом (issue): у Migros нет координат, у Talabat
  нет списка веток.

## Шаги

1. Миграция `0050_aggregators.sql`: схема `agg` — `points`, `ratings`, `loads`; блок
   `aggregators` в `ratings.layout`.
2. `src/db/agg_store.py`: запись снимка, журнал, последняя удачная загрузка, чтение для
   страницы.
3. `src/ratings/aggregators/`: общий HTTP с паузами и повтором на 429; сборщики по одному
   модулю на агрегатор; `collect.py` — обход, привязка, страж пустого ответа, CLI.
4. `src/bot/agg_loader.py` + запуск в `src/bot/app.py`.
5. Блок на странице: шаблон, тексты ru/en, компоновка.
6. Тесты ядра: разбор ответов агрегаторов, привязка, страж пустого ответа (данные,
   которые читают как факт). Остальное — запуском на живом продукте.
7. Док `docs/17-aggregators.md`, ссылки в README и docs/15; первичное заполнение
   справочника и первый сбор на проде.
